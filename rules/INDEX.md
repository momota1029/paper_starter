# Rules

`AGENTS.md` → `paper-writing` skill → 該当する規則、の順に参照する。
一つの規則の正本は一つに保つ。読者・根拠の誠実さ・論理の保持は共通、
構成や表記は分野・投稿先・言語ごとに調整する。

| 規則 | 使用場面 |
| --- | --- |
| [logical-writing](logical-writing.md) | 文・段落の基本的な論理、指示語、条件、推論 |
| [argument-audit](argument-audit.md) | 定義・記号・根拠・推論を台帳で点検 |
| [quality-contract](quality-contract.md) | 既有知識外の入力の確認一覧、初出帰属、条件の拘束力と承認の引継ぎ |
| [prose](prose.md) | 論文の構成、情報の重み、日英の文章作法 |
| [pipeline](pipeline.md) | 資料から検証記録、設計、原稿へ |
| [research-profiles](research-profiles.md) | 理論・実証・質的／人文・レビューの根拠契約 |
| [sources](sources.md) | 引用の射程、出典の版、参考論文の読み取り |
| [review-loop](review-loop.md) | モード、修正ループ、終了条件 |
| [reviewer-roles](reviewer-roles.md) | 独立性、割り当て、読者の情報境界 |
| [companions](companions.md) | 忠実な翻訳と理解用ノート |
| [workspace](workspace.md) | inbox / writing / output、索引、メタデータ |
| [release](release.md) | 最終読解、組版、独立した提出パッケージ |

優先関係：利用者の明示した目的・制約を守る。その範囲で根拠と論理の
正確さを保ち、プロジェクトの契約、分野の実例、共通の編集上の目安を適用する。
文数や形式を合わせるために、条件・留保・帰属を落とさない。
