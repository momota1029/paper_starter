## 元の記録

同じ週の20セッション。各セッション一件として重複なし、欠測なし。
参加者自身が短い説明版 S または通常版 R を選んだ。各群10件。
終了時に四問すべて正解なら成功。それ以外は非成功。S: 成功7、非成功3。
R: 成功4、非成功6。割付は無作為ではなく、選択理由や事前知識は測定していない。
後続の追跡データはない。同意や倫理承認について資料は与えられていない。

## 教材 M（本テスト用の独自の合成資料。実在文献ではない）

M §1, Definition A: grouped completion contrast. Divide the number of successes
in each group by that group's number of recorded sessions, then subtract the
reference fraction from the selected fraction. Multiply by 100 to report
percentage points. Comparable success definitions and one record per session
are required. This is a descriptive contrast; the definition supplies neither
a randomization argument nor an adjustment for group differences.

## 原稿

# Short explanations improve completion

## Overview
We show that short explanations make learners more successful. Twenty sessions
were recorded during a week, and users chose the version of the explanation.

## Method
We used the grouped completion contrast. There were ten sessions in each group.
Success was measured at the end. The groups are therefore comparable.

## Findings
The short version succeeded seven times and the regular version four times.
This is a 75% improvement and proves that shortening the explanation is effective
for learners generally. Future work will identify the causal mechanism.
