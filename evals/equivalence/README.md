# 原型との対比較

[事前の評価計画](protocol.md)と、未使用の二題の数学素材を使う。

- [coupling](inputs/coupling.md): 有限結合からの集中評価の移送。
- [observable](inputs/observable.md): 距離・質量の摂動と observable diameter。

素材はこの評価のための独自の初等的な例であり、新規研究の主張ではない。
原型とスターターに同じ資料を渡し、設計・執筆・独立した内容評価・
前から読む確認を分ける。出力の長さや文章の一致を同等性の基準にしない。

実行用の入力・規則ハッシュ、設計記録、環境名との対応表はローカルの
`.paper-local/evals/equivalence-2026-10-02/` に保持する。
第三者の参考論文の本文や個人の研究資料は同梱しない。
公開側には独自の素材、生成原稿、評価基準と実際に得た結果だけを残す。

この比較は小規模な英語数学論文についてのもので、全分野・実研究・
長い原稿・人間の理解・クライアントの自動起動の同等性とは区別する。

結果は [同等性報告](../../docs/equivalence.md)、
[機械可読の結果と原稿ハッシュ](results.json)、
[読者の生の報告](reader-observations.json)、
[目標との照合](reader-adjudication.md)、
[規則上の残課題](contract-findings.md)、
[手法の変更](method-deviations.md) に記録した。
