# 同等性確認で残った不足の補強 — 2026-10-02

前回の監査で見つかった三つの規則差を、分野ごとの
[品質契約 Q01–Q03](../rules/quality-contract.md)として補強した。
前の数学二題を採点し直さず、新しい三分野の素材で修正・独立監査・再確認を実行。
これで既知の契約上の穴は補ったが、**全分野の完成論文についてのdoc同等性を
認定したわけではない。** [前回の未達判定](equivalence.md)もそのまま残している。

## 変えたもの

- **外部入力:** 読者の既有知識外の概念・結果・方法・解釈について、定義と範囲、
  使える内容、今回への適用を本文の位置とともに確認。指摘なしの報告にも
  網羅的な確認一覧を要求し、専門家の知識で省略を補って合格にしない。
- **帰属と分野差:** 借用概念の初出と帰属位置を照合。初出引用が必要な契約は保持し、
  段落末引用が認められる分野へ数学の位置規則を押し付けない。
- **厳しい条件の継承:** hard / strong / weak と、実際に認められた例外の由来を
  記録。著者承認を創作せず、通常の裁量には不要な承認待ちを増やさない。
- **初読の実行と観測:** [順次読者CLI](reader-runner.md)を同梱。本文を一片ずつ渡し、
  対象・条件・根拠・限界の説明を次の片の前に保存。元の応答を集計で差し替えられない
  よう照合する。隔離や理解を自動認定せず、別担当が実観測と目標を照合する。

スキルの入口、設計・執筆・論証・出典・構造の役定義、ひな型、最終記録検査へ
接続した。新規プロジェクトの品質契約は未設定で始まり、空の確認一覧や未設定を
最終合格には使えない。`skill-creator` に沿い、既知の失敗を直してから未使用素材で
試し、正常な対照例を壊さないことも別に確認した。

## 実際の検証

[事前計画と全素材](../evals/contract-transfer/README.md)を保存した。
資料N/M/Qは全て独自の合成教材で、実在文献の探索を済ませたという実験ではない。

| 検査 | 観測された結果 |
| --- | --- |
| 理論: 外部補題・残差評価・数値例 | 別の専門担当が全条件・適用・初出帰属と数値を確認。対象範囲の欠陥なし |
| 実証: 非無作為の二群比較 | 分母・方法・30ポイントの差・非因果の射程を保持。架空表示の不足を別の目標照合で検出し一文追加 |
| 史料解釈: 発言と後年の注 | 引用・声・解釈限界は適合。Vの委員所属を推測する一語句を監査が検出し、局所修正後に閉鎖 |
| 良好な対照 | 段落末帰属・承認済み構成・普通の語の無定義を誤って違反にせず、本文を保持 |
| 実読者 | EとE-v2を別の新規Luna/highで三片ずつ提示。原版の文字通りの不足を保持。修正版は独立照合で三境界すべての事前目標を達成 |
| コードと記録 | 独立監査が集計要約の差し替えの穴を再現。原応答・全区切りとの照合を追加し、別担当が拒否条件を再確認 |
| 自動テスト | 62件すべて成功。ローカルリンク・設定・skill検査も成功 |

詳細は [専門監査](../evals/contract-transfer/specialist-observations.md)、
[読者照合](../evals/contract-transfer/reader-adjudication.md)、
[実装監査](../evals/contract-transfer/runtime-audit.md) を参照。
数値や一致した評価だけで、全体の品質を認定しない。

## 残る範囲

長い実研究論文、日本語・翻訳、多分野の全長原稿の原型との対比較、実文献の探索と
複雑な外部理論、通常モデル構成での比較、nativeの役割発見・自動隔離、人間と
分野専門家の最終通読は、今回の補強テストでは未確認。
補助CLIはテキスト専用で、PDF・TeXの前方読みや表示品質を保証しない。

元のdocのファイルは読取りだけで、保存済みハッシュも一致した。利用者の
グローバル設定、公開先への変更、commit / pushは行っていない。
個人パスを含むrawログは非公開領域に残し、公開用の記録には含めていない。
