# 品質契約の案内

このファイルは [品質契約](../../rules/quality-contract.md) の適用方針と正本の
所在だけをまとめる。同じ判断・根拠を複写せず、既存の design.md / evidence.md /
corpus.md の節・IDへ参照する。未設定・未確認・該当なしを区別する。

## 読者と外部入力 — Q01

- 読者の既有知識と境界: TODO — design.md の該当節を指定
- 対象原稿・版・範囲: TODO
- 既有知識外の入力の確認一覧: TODO — evidence.md の該当節を指定

確認一覧には入力ごとの定義・範囲・正規化、使う内容と出典版・正確な位置、
今回の対象・条件充足・結論・目的の原稿位置、判定を記す。
監査報告にも合格時を含めて一覧と検査範囲を返す。入力がなければ none と理由を記す。

## 初出と帰属 — Q02

- 借用概念等の帰属を示す位置の方針・根拠: TODO — design.md の該当節を指定
- 初出・帰属索引: TODO — evidence.md の該当節を指定

索引は概念等の ID、借用／採用／再定式化の区別、実際の初出、帰属位置、
出典版・正確な位置、適用する方針、判定を含む。初出引用の要否は分野契約で決める。
該当する借用がなければ none と理由を記す。

## 条件の強さと著者判断 — Q03

- プロジェクトの条件と判断: TODO — design.md の該当節を指定
- 近接論文の実物・観察・採否: TODO — corpus.md の該当節を指定

各条件に ID、範囲、hard / strong / weak、由来の正確な位置、今回の選択、
逸脱理由、既存の承認条件、実際の承認の所在と範囲を記す。
引き継いだ必須条件を弱めず、既存の承認と裁量を再利用する。
未決の判断はその条件に依存する作業だけを保留する。
